# Introduction 
This project focuses on time series forecasting and machine learning models applied to 
stock price data of Wipro Limited (WIT) from 2021-06-21 to 2024-07-20. The primary goal is to leverage various statistical and machine learning 
techniques to predict future stock prices accurately. We will explore both univariate and 
multivariate forecasting methods, starting with traditional statistical models and advancing to 
sophisticated machine learning algorithms.
